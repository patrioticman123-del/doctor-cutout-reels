# 復健科與骨科：編劇規格

## 來源先行

先整理 1–3 個觀眾能帶走的訊息，再寫故事。官方衛教、專科學會、政府機關與現行指引優先；區分適用族群、時間點和證據程度。主題需要時補查緊急就醫訊號。廣告、搜尋摘要及未附來源的貼文不能單獨支持臨床說法。

在 JSON 的 `sources` 記錄 `id`、`title`、`url`、`accessed`、`supports`。每幕 `claims` 對應來源 ID。純笑話、角色表演及 CTA 可留空；renderer 只能檢查結構，無法判定醫學真假，執行 skill 的 AI 仍須逐句比對。來源不足時縮小論點，必要時詢問使用者，不虛構研究、療效、百分比或學會背書。

保留「可能」「部分患者」「需依情況」等限制。不要用「所有疼痛都是」「一定免開刀」等結論。別為了笑點提供危險動作示範、具體個人診斷、藥物劑量或保證療效。特定疾病、族群與地區的法規要求需依實際主題查證，不在通用模板中寫死。醫療內容預設 `content_type: medical`，必須有來源；交付可公開使用前仍需醫師審閱臨床內容。

## 像短劇，而不是醫學簡報

醫師：冷面、句子短、專業但有反應。阿洛：學生，直白好奇、把推論帶向荒謬。美芳：成年家長，替一般成人觀眾追問限制。題材涉及成人患者時，使用成年角色承接情境，學生可以提問，但不能把成人建議套到兒童。至少 75% 的幕是角色接話，避免醫師長篇獨白。

固定場景為原創教室、虛構青禾小學校園與一般街道。避開原作角色服裝組合、標誌配色、地標、校徽與台詞；借用平面剪紙與喜劇節奏，不複製既有角色。所有角色在每張分鏡都維持相同尺寸、腳底對齊，不能因為說話者不同而縮小另一個人。

影像本身就是 9:16 滿版場景，不能把一張橫圖放在中央、上下面板放標題。標題和幕號留在審稿網頁，影片只用可選的畫內對話字幕。每幕寫出手部姿勢，與說話內容配合：解釋時指黑板、介紹教具時攤手、學生提問時舉手、收尾可揮手；不要整支角色只站著口播，也不要每句都重複同一姿勢。

節奏參考：

| 段落 | 故事動作 | 鏡頭與聲音 |
|---|---|---|
| Hook | 角色提出具體、荒謬或有張力的情境 | 直接入戲，第一幀有衝突 |
| Escalation | 錯誤推論加碼，暴露盲點 | 對切、音效短促 |
| Turn | 醫師用一個事實打斷 | 同尺度對話構圖，縮短台詞 |
| Explain | 用道具或情境把核心講明白 | 一幕一重點，字幕分段 |
| Reaction | 搭檔反應並回扣開頭 | 留約 0.3–0.6 秒冷場 |
| Payoff / CTA | 笑點收尾，給觀眾一件可做的事 | 最後畫面保留閱讀時間 |

這不是每支片必須六幕的硬規則，也不要求每集都有人說錯話。可從學生觀察模型、醫師在黑板畫關係、生活事件、家長追問或猜題開始。換主題時要重寫情境、道具與笑點。避免讓病人的痛苦變成笑點，或把「不看醫師」「硬撐訓練」演成正確答案。

## 可混用的演法

| 演法 | 故事用途 | 分鏡要看得到的東西 |
|---|---|---|
| 黑板講解 | 醫師把關係整理清楚，學生接著追問 | 可讀標題、1–3 個重點、箭頭與指示棒 |
| 骨頭模型示範 | 從教具觀察引出問題，不只站著口播 | 桌上模型、支架、標示與同尺度師生 |
| 學生猜題 | 讓角色選擇、解釋理由，再由醫師回應 | 黑板題目與選項；不要一開始直接公布答案 |
| 並列比較 | 區分兩種情況或概念 | 兩張並列說明卡，保留限制與適用條件 |
| 生活情境對話 | 把知識連到觀眾會遇見的事 | 校園或街道事件與角色互動 |

通常挑 2–4 種適合主題的方式，不強制全部用。黑板上的每個醫療重點也要有來源，不能只有口白受查證。現有骨頭教具是一般長骨形狀的簡化示意，不可拿它冒充精確的膝、肩、脊椎結構或病灶。需要特定解剖示範時，先依可靠資料擴充對應模型並重新交分鏡審閱。

## 寫完要讀出聲

每句大約 12–28 個中文字，避免連續專有名詞；實際秒數以 TTS 音檔為準。繁中字卡一至兩行，每行最好 8–12 字。重要醫療限定詞不能只放在小字。一次反轉通常比列五個衛教重點更有記憶點。

先按字數估 30–60 秒，交完整腳本、每幕靜態分鏡、動作和反應供使用者修改。沒有明確確認之前不合成配音、配樂或影片。每次修訂重交分鏡；確認後若實際配音過長而要改台詞，也要讓使用者看到修改版。
